
## 20260710B -- Thoughts and Tasks on Cosine-Similarity Scoring Tree's Possible Weakness 

奥博特，你好. 今天我们再来一个轻松泛谈，讨论一下Cosine-Similarity Scoring Tree's Possible Weakness

1。Cosine-Similarity Scoring Tree is the Backbone Metric Space Structural Intelligence。

    1A) It is very effective;
    1B) It seams the only game in town to choose;
    1C) There might be some hole/Weakness in it. Need to carefully investigate.

2 让我们通过有关 i）中文汉字的产生与拓展过程；ii）小孩三猫推理；iii）UTN；的思想实验来作为这个研究/调查的切入点。

3。是否可以这样假设：人类文字的产生与人脑子里概念与语言的产生机理与智慧是有很强的镜像关系，某种DUAL。以中文为例：

    3A）中文最早的一些字（如甲骨文）是图像文字。即含义的图画的压缩。
    3B）最早的文字不多，形成一个比较小的差分树。
    3C）这些文字的识别，可以用Cosine-Similarity Scoring Tree较完美地实现。

    3D）当文字发展要发明新字的时候，造字就不完全按图像文字的规则来造了。有了，
        3D1）仍是图像文字；
        3D2）已知文字的差分树加了分支标注的分叉；
        3D3）发音文字；
        等等。

4。这些中文文字生成的几种方式，明显是受MET驱动，有道理的的。也反应了造字人头脑中的语言智能模型的意见/主张的体现。

    4A）而这种非完全图像文字非给基于图像元素统计的Cosine-Similarity Scoring Tree的上空带来了一朵乌云。

5。同理，小孩三猫推理中第四只，第五只，。。。猫很可能就是简单加标注的差分。不是完全/重来的差分。

6。同理，UTN也可能有大量简单加标注的差分。不是完全/重来的差分。

7。解决这个困惑，比较指向"识别"+统计的Hybrid算法改进方向。可能要引起我们的一个研究侧重。
